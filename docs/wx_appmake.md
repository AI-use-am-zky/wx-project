# 宠物空运微信小程序 — 第一期共识

拷问结论已确认。按本文范围做，未写进本文的（铁路、专车、多宠一单、租箱、跳转顺丰小程序下单等）第一期不做。

## 产品一句话

给宠主用的微信小程序：只做宠物空运、门到门；钱付给服务商；服务商后台调用顺丰接口下单。页面结构和关键交互参考「派到宠物出行」的空运链路，不抄其品牌、插画和文案，也不做其铁路 / 专车 / 社区 / 商城。

## 角色

- **C 端**：宠主估价、下单、支付、查进度、联系客服、申请退款、填发票抬头。
- **服务商**：本人使用轻量管理端；新单 / 失败单微信通知。第一期一个管理员账号。

## 关键决策

| 项 | 结论 |
| --- | --- |
| 用户 | 宠主 C 端；服务商用轻量管理端 + 微信通知处理异常 |
| 产品 | 仅空运；城市跟顺丰宠物空运能接的走；不接其他承运商；一单一只宠物 |
| 履约 | 门到门（无自送 / 自取选项）；宠主选上门取件日，时段和航班按顺丰可约时间排 |
| 价格 | 填好寄件、收件**详细地址**后才估价；能问到顺丰则用顺丰询价 + 加价，失败或超时用自有价表 |
| 加价 | 后台可配：默认比例 + 最低服务费；城市例外价以后再加；具体数字后定 |
| 支付 | 微信支付，宠主只付给服务商（运费 + 服务费 + 加购）；公司主体商户号 |
| 发票 | 电子普通发票；付款后可填抬头，**签收后才开具**；退款未完成的不开 |
| 顺丰 | 后台调接口出运单；寄件人 / 收件人 = 真实开门联系人；月结账号可以是公司的 |
| 出单时机 | 支付成功后立即尝试向顺丰下单；失败则进入人工待处理，不自动退款 |
| 差价 | 上门复秤与下单重量相差 **1kg 以内忽略**；超出则补差或转人工 |
| 退款 | 未揽收可退；已向顺丰下单但未揽收则扣固定手续费（金额后定）；已揽收不退，改期另走。顺丰撤不了的单转人工，小程序不假装一定能退 |
| 品类 / 证件 | 跟顺丰允许的宠物品类走；校验按顺丰规则；代办作为加购 |
| 加购 | 卖航空箱（不租）、代办检疫、顺丰运单保价 / 声明价值 |
| 航空箱 | 默认自备并在支付前上传箱照；加购为买新箱，按顺丰允许尺寸推荐 |
| 进度 | 业务节点 + 顺丰路由合并一条时间轴；运单号可复制。路由接口未通时先只展示业务节点 |
| 账号 | 逛首页 / 订单空态 / 我的 / 协议等不强制登录；**进入选城市或开始填下单信息必须登录**；估价、支付均在已登录状态。支付前授权手机号。订单绑定该微信账号 |
| 估价字段 | 地址 + 品种 + 体重 + 取件日即可出价；支付前再补宠物近照、自备箱照、检疫资料（勾选代办则改填代办所需信息） |
| 消息 | 支付成功时申请订阅消息（已预约上门、异常 / 需补差、已签收）；拒绝则只看订单页 |
| 客服 | 小程序客服会话 + 电话 |
| UI | 学结构和关键交互（估价卡片拆行、表单分页、订单时间轴密度）；底部典型为「首页 / 订单 / 我的」；品牌色和名称自有 |
| 技术 | 第一期微信原生小程序 + 自建后端。以后若要 uni-app / Taro / App，重写小程序前端，后端接口可复用 |
| 资质 | 公司认证小程序 + 微信支付 |

## 主流程（宠主）

1. 未登录可浏览非下单页。
2. 进入选城市 / 填写下单信息 → 微信登录（含手机号授权）。
3. 填写寄件、收件详细地址、品种、体重、取件日期 → 询价（顺丰优先，失败走价表）→ 展示应付（运费 + 加价 + 可选加购）。
4. 支付前补齐照片 / 箱 / 检疫（或代办信息），可勾选买箱、代办检疫、顺丰保价；同意运输协议。
5. 微信支付；申请订阅消息；尝试自动向顺丰下单。
6. 订单详情看合并时间轴；异常 / 补差 / 退款走客服或订单内申请，服务商在管理端处理。
7. 签收后开具电子发票。

## 服务商管理端（第一期下限）

- 订单列表 / 详情、失败原因、手动重新向顺丰下单、改价补差、退款、查看或补填顺丰单号。
- 新单、下单失败微信通知。
- 可配置加价比例和最低服务费（数字后补）。
- 第一期不做：多员工权限、复杂报表、完整对账中心。

## 明确不做（第一期）

- 铁路、专车、地面单独产品、一单多宠、租航空箱、跳转顺丰小程序让宠主付款。
- 对标派到的活动、社区、商城等非空运履约页面。
- 短信通知、管理端手动群发、跨端 App。

## 开放风险（会迫使改决策）

- 顺丰宠物空运的下单、询价、保价、路由、可约上门时段若缺失或不稳定，即时估价和自动下单会大量转人工。
- 加价比例、最低服务费、退款手续费未定，可能亏本。
- 城市完全跟顺丰走，本地接宠或目的地派送接不住时只能拒单或改覆盖规则。
- 企业小程序、微信支付、电子发票、顺丰月结任一未就绪，主流程无法上生产。
- 若顺丰保价套不上，保险加购要改成服务商保价或下线。

## 开工前待准备

- 顺丰开放平台账号与宠物空运相关接口文档（下单、询价、路由、揽收预约、保价）。
- 微信小程序 AppID、公司微信支付商户号、电子发票能力。
- 加价比例、最低服务费、未揽收取消手续费的具体数字。
- 客服电话；运输协议 / 免责文案。
- 自有兜底价表（至少覆盖询价失败时的卖价逻辑）。
